# P1｜关系边界

## 三种动作必须分开

### 算啦

针对某一条 Commitment。任一方确认后进入 `LET_GO`，双方看到共同事实；原话仍保留在“后来”，不提供原地复活。

### 收起这段关系

当前用户的个人界面偏好：`VISIBLE → HIDDEN`。对方不收到通知，共同状态不变。首页、自动冒泡、回忆和非必要推送统一排除，但历史仍可访问。

### 不再接收新提议

通信权限：`acceptsNewProposals = false`。过去内容不删除，系统不主动通知对方；发送端只得到“对方目前没有接收新的下次”，且不能绕过。

## 合法组合

用户可以继续看见一段关系但拒收新提议，也可以收起关系但继续接收，或两者同时发生。新 Commitment 成立不得擅自恢复关系可见性。

## 私人“我还想”

在 `LET_GO` 后，用户可以留下 `WANT_STILL / SELF_ONLY`。它不通知对方、不写入对方时间线、不恢复共同状态，也不生成新 Proposal。

## 产品文案边界

- 不使用“拉黑”“删除关系”“结束关系”等扩大含义的词。
- 不展示屏蔽原因、收起天数、关系评分。
- 权限阻止送达时，不引导用户换方式联系。
