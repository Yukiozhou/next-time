# P0｜产品宪法

这些规则优先于页面、文案与增长目标。

1. **一个人说的不算。** 只有双方明确确认，才形成共同的 Commitment。
2. **共同建立，任一方可以退出。** 建立共同未来需要两个人；继续参与不能强迫任何一个人。
3. **不催促。** 产品可以让内容浮起，但不能利用焦虑、红点或惩罚逼迫完成。
4. **不抹掉。** 兑现与算啦都会进入“后来”；结束不等于删除历史。
5. **共同事实一致，私人感受可不同。** SELF_ONLY 信号不通知、不冒泡、不改变共同状态。
6. **时间是环境，不是倒计时。** “池”容纳沉下去的以后，不代表失败或过期。
7. **边界默认尊重。** 收起只改变自己的界面；拒收阻止未来送达；系统不提供绕过方式。
8. **后端状态是真相。** 前端不能假装自己是唯一视角；幂等处理重复打开与并发变化。
9. **状态成功后才有 Magic。** 网络失败时保持原状态，不预演成功动画。
10. **原话优先。** UI 不把人的话改写为机械任务标题。

## Critical Interaction Laws

| 行为 | 改变 | 是否影响对方 |
|---|---|---|
| 算啦 | `Commitment.sharedState → LET_GO` | 是，共同未来结束 |
| 收起关系 | `RelationshipVisibility → HIDDEN` | 否，只影响自己 |
| 不再接收 | `acceptsNewProposals → false` | 未来提议无法送达 |
