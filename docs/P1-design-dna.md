# P1｜Visual Master / Design DNA

## 真理来源

视觉以 **919 UI 第二版**为母版，并叠加 V3 的视觉减法：轻盈日常、明亮印象派浅池、只在关键状态出现一点魔法。禁止回到早期的深绿夜水方案。

## Token

- `Cloud Ivory #FAF7F1`：日常背景与主要留白。
- `Ink #263238`：正文与共同事实。
- `Soft Ink #73777A`：解释和时间信息。
- `Apricot #E99A7B`：人的动作与主 CTA。
- `Butter Star #F3D66B`：星星与极少数关键强调。
- `Monet Sky #BFD4E7`：时间水色和远处层次。
- `Pool Aqua #A8D8D4`：明亮浅池。
- `Rose Petal #E9BDC3`：池中的暖色花影，不作情侣主题。

暖色代表人和发生；水色代表时间和安静下来。普通页面约 5–10% magic；池可以达到 60% art/magic。

## 排版与结构

中文原话可使用克制的宋体气质；操作、正文使用系统黑体；状态标记使用等宽体。Relationship 是连续空间，以留白、标题和细分隔线组织，不使用三个并列状态 Tab，也不采用 card-first design。

## Signature：M01 星星触水

Cloud Ivory 日常背景保持可见；页面底部出现一小片明亮浅水。Butter Star 轻轻触到水面，产生一至两圈柔和 Ripple，然后出现“我们说好了”。星星不是坠入深处；不得使用黑绿、深海或夜水。

## Pool

池是空间隐喻，不是内容卡片列表。默认只看到 5–8 颗小星与明亮池底，不显示原话；选择一颗星后，其他星淡下去，才显示原话与“捞起来 / 再看看”。

## 动效与可达性

日常转场 180–320ms；M01/M02/M03 只承担状态反馈，不承担提交逻辑。支持 `prefers-reduced-motion`；控件有语义标签；不以颜色作为唯一状态信号。

## 禁止项

不使用深海夜水、黑绿森林系、心形、情侣粉紫、任务勾选、完成率、烟花庆祝、破碎失败动画、SaaS 卡片墙或通用 AI 渐变。
